** Creating subagents **
- Like the Agent tool, /call invokes subagents.
- Specify forked or fresh context when making a /call.
- Run independent tasks concurrently, e.g. "/call in parallel do this, this other thing, and yet another thing" or "/call Explore all available moves" at the same time.
- Unlike the Agent tool, called agents can interact with the user. Also, called agents can themselves call to decompose work across an agent hierarchy.
